## Findings (not failures)

- **An old install job is still set.** `status` lists `00:0c:29:f2:2f:4d (ohne Inventar)` with `PXE-Job: install`, set on 2026-11-17 16:52 (the M4 test). The server was not reverted to `server-clean` before this test. That VM (`mtx-pxe`) installs Ubuntu again at its next network boot. Remove it before M5 with `./migratux stop 00:0c:29:f2:2f:4d`, or revert the snapshot.
- **`manifest.sha256` belongs to root.** Moving it in step 2 needed `sudo` (the guide already has the `|| sudo mv` fallback). The backup files on the share are written by the Samba container.
- **Mixed languages.** `status` uses German labels (`Inventar`, `ja`, `keiner`, `ohne Inventar`), `help` and the log are English, the start hint is German (`Jetzt den PC neu starten …`). Matches the "user-facing text in German" choice, but the technician sees both.
- **Guide, step 4:** the command is written inline with backticks; copied with the backticks, the shell runs it as a command substitution (`2026-11-17: command not found`). A code block like in steps 1–3 would avoid that.
